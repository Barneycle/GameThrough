# GameThrough frontend

React + Vite UI for GameThrough. See the **root README** one folder up:

`../README.md`

```powershell
npm install
npm run dev
```

Opens on http://localhost:3001. The API must be running on http://localhost:3000.

On Vercel, set Root Directory to this folder and set `VITE_API_URL` to the live API URL before building. See the root README deploy section.
